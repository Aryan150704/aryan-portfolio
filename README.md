# Aryan Chaudhary Portfolio 

A cinematic, interaction-heavy static portfolio.

### Includes
- Full-screen preloader
- Canvas star field
- Custom cursor with hover context
- Magnetic UI
- 3D tilt project cards
- Parallax hero typography
- Animated counters
- Rotating engineering/performance visuals
- Full-screen navigation
- Scroll-driven reveal system
- Responsive mobile design
- Case-study storytelling focused on engineering outcomes
- No build step

Open `index.html` directly or run `python -m http.server 5500`.

The content is based on the supplied resume. Profile URLs were not invented because the resume listed GitHub/LinkedIn/Portfolio/LeetCode without actual URLs.
